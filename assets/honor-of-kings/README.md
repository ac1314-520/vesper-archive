# Honor of Kings sample covers

This folder contains the 170 covers used by the VESPER archive Honor of Kings
cards, serials `101/271`–`270/271`.

| Category | Count |
| --- | ---: |

| 珍品无双 (Precious Unparalleled) | 1 |
| 无双 (Unparalleled) | 14 |
| 珍品传说 (Precious Legend) | 12 |
| 传说 (Legend) | 23 |
| 史诗 (Epic) | 50 |
| 勇者 (Brave) | 50 |

Metadata and frame palettes live in
[`../../src/honor-of-kings-cards.js`](../../src/honor-of-kings-cards.js).
Per-card source records are in [`sources.json`](./sources.json).
