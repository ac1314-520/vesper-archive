# Ultimate prize cover

`longgeng-cat.webp` is the site owner's cat photograph used for the VESPER
ultimate-prize card **「长庚猫猫」** (serial `271/271`).

The card is not part of the regular rarity pools. It is rolled independently at
**0.05% per pack**; drawing it in the first two packs / within 10 collected
cards can generate a local milk-tea voucher.

The photograph is supplied by the site owner for this personal fan project and
is not MIT-licensed. See [`../../NOTICE.md`](../../NOTICE.md).
