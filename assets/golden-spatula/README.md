# Golden Spatula sample covers

This folder contains the 82 local covers used by the VESPER archive filler cards
(serials `019/271`–`100/271`).

## Files

- `019.webp`–`100.webp`: local card covers.
- `sources.json`: per-card source URL, category, and original name.

## Categories

| Category | Count |
| --- | --- |

| 至臻不朽 | 6 |
| 普通神话 | 25 |
| 英雄级 | 20 |
| 传说级 | 20 |

The matching metadata, frame palettes, and rarity mapping live in
[`../../src/golden-spatula-cards.js`](../../src/golden-spatula-cards.js).
